# Reference collection

Six unmodified medium JPEGs from the NASA Image and Video Library, used as an
illustrative collection in `/photos`. Each is 1280 × 851 pixels. The short titles
in the application are display labels; dates are catalog dates, not fabricated
capture times. Captions and favorites start empty and belong to the local session.

Asset URLs follow `https://images-assets.nasa.gov/image/{id}/{id}~medium.jpg`.
Metadata was checked against `https://images-api.nasa.gov/search?nasa_id={id}`.
The originals are retained locally so the example does not need a live photo API.
NASA is a source of photographs, not an affiliate or user of Continuity.
